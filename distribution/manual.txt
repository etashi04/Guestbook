이계의 숙박부 한국어 패치 v1.0.0
원제: 異界ノ宿帳 / 한국어 임시 명칭: 이계의 숙박부
배포: https://github.com/etashi04/Guestbook/releases/latest
지원: Windows 64비트 / Steam App 4249520 / 게임 빌드 26645119
표시 언어: 일본어(日本語) 슬롯에 한국어를 적용합니다.

설치 전 게임을 완전히 종료하세요. 다른 빌드나 다른 모드로 변경된 파일에는 적용하지 마세요.
게임 업데이트 후에는 해당 빌드에 대응하는 패치를 사용하세요.
패치는 대사·선택지·UI·화자명 및 이미지·JP 영상 한국어 자막을 포함합니다.
JP 영상은 체험판 종료용 소개 영상이므로 본편 엔딩에서는 원래 재생되지 않습니다.
이 패치는 세이브와 Steam 클라우드 설정을 변경하지 않습니다.

수동 설치
1. 수동 설치 ZIP을 새 폴더에 모두 압축 해제합니다.
2. Steam 라이브러리에서 게임 관리 → 로컬 파일 보기를 눌러 Guestbook.exe가 있는 폴더를 엽니다.
3. 아래 원본 4개 파일을 게임 폴더 밖에 경로 구조 그대로 별도 백업합니다.
   Guestbook_Data/sharedassets0.assets
   Guestbook_Data/level0
   Guestbook_Data/il2cpp_data/Metadata/global-metadata.dat
   Guestbook_Data/StreamingAssets/Movie/demo_jp.mp4

4. ZIP의 「패치파일」 폴더 안에 있는 Guestbook_Data 폴더를 Guestbook.exe가 있는 곳에 붙여넣고 병합·덮어쓰기합니다.
   「패치파일」 폴더 자체를 복사하거나 Guestbook_Data 안에 한 번 더 넣지 마세요.
5. Steam에서 게임을 실행하고 표시 언어를 일본어(日本語)로 설정합니다.

원본 복구
게임을 종료한 뒤 따로 백업한 원본 4개 파일을 같은 위치에 덮어씁니다.
백업이 없거나 게임 업데이트 후에는 Steam의 설치된 파일 → 게임 파일 무결성 검사를 이용하세요.
수동판은 자동 백업을 생성하지 않습니다. 자동 설치기의 원본 복구 기능 대신 위 절차를 사용하세요.

주의
원작자·개발사·배급사와 무관한 비공식 한국어 팬 패치입니다.
게임 업데이트 후 호환되지 않을 수 있습니다.
배포 파일은 SHA256SUMS.txt로 무결성을 확인할 수 있습니다.
함께 배포한 「제3자_라이선스_고지.txt」를 확인하세요.
